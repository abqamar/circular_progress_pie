# Changelog

## [0.0.1] - 2025-09-27

### Added
- Initial release of Pie Progress Indicator
- Basic pie progress with custom colors
- Circular ring progress variant
- Percentage indicator with text
- Gradient support
- Multiple animation types
- Customizable start angle and direction
- Smooth animations with configurable duration/curve

### Features
- `PieProgressIndicator` - Main widget with all customization options
- `PieProgressIndicator.circular()` - Ring-style progress
- `PieProgressIndicator.percentage()` - Percentage text indicator
- `PieProgressIndicator.gradient()` - Gradient progress indicator
- Four animation types: sweep, fill, bounce, elastic
- Support for center child widget
